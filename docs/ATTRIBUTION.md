# Source attribution & provenance

## Reference use

https://www.branah.com/ was consulted **only as a functional reference** for which languages/layouts
exist and where each character sits on the keyboard (key positions and modifier states). This is
factual layout information.

**Not** copied from the reference site (or any third party): source code, HTML/CSS/JS, fonts, images,
or any other protected asset. All mapping data in `languages/` was authored independently as plain
data, cross-checked against publicly documented national/standard keyboard layouts (e.g. ISO/IEC
9995 national standards, vendor layout charts, Unicode charts).

Each layout file also carries a `provenance` block with its `reference` URL, `verification` level and
free-text `notes`.
